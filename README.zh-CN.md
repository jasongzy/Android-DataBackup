<h1 align="center">铱备份</h1>

[English Doc](README.md)

铱备份是[钛备份](https://www.titaniumtrack.com/titanium-backup.html)功能与应用中心操作逻辑的现代化原生 Android 实现，需要 Root 权限。

## ✨ 功能

- 为每个应用保留和管理多个备份记录
- 自由选择 APK 及数据备份与恢复的范围
- 使用彩色标签、筛选、搜索和排序管理应用
- 支持单个应用备份与多选批量备份
- 支持本地存储及云存储服务
- 支持 Android 多用户与系统应用

## 📥 下载

请从 [GitHub 最新版本](https://github.com/jasongzy/Android-DataBackup/releases/latest) 下载通用 APK。

- Android 7.0 或更高版本
- 通过兼容的 Root 方案获得超级用户权限
